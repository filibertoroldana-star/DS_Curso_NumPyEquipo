## 🛠️ Metodología de las 5 Fases
El proyecto fue estructurado bajo un estricto flujo de ingeniería de software:
1. **Setup y Arquitectura:** Creación del repositorio y estructura de directorios (`src/`, `notebooks/`, `data/`).
2. **Distribución de la Carga Ágil:** Mapeo de videos del curso y división equitativa de tareas mediante tablero Kanban.
3. **Desarrollo Aislado y Control de Versiones:** Creación de ramas independientes (`feat/`) y commits semánticos.
4. **Code Review e Integración:** Apertura de Pull Requests (PR) con revisión cruzada obligatoria antes de hacer *merge* a `main`.
5. **Documentación y Cierre:** Pruebas de reproducibilidad local y en la nube.
